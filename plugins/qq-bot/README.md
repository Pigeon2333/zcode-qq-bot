# qq-bot — ZCode QQ 机器人

面向公开发布的 QQ 群聊 AI 机器人桌面应用（品牌「ZCode QQ机器人」）：**人设、风格模仿、长期记忆、看图、表情包自管理、防滥用防护、主人任务沙箱、私聊遥控、AI 生图、夜间自动复盘**。完全自治运行，不依赖 ZCode 会话；本插件目录是项目源码仓与开发工作台。

## 功能总览

| 能力 | 说明 |
|------|------|
| 消息收发 | OneBot v11 正向 WS（NapCat Shell），纯标准库实现，断线自动重连 |
| 回复模式 | 标准（仅@/回复）/ 关键词 / 闲聊（概率+最小间隔+防插嘴+感兴趣判定）；群消息总开关 |
| 人设系统 | 多人设即时切换 + 全局通用设定 + 重命名（联动自进化/表情库/目录） |
| 风格模仿 | 模仿指定群友语言风格（不冒充身份）+ 自进化风格观察（每 6 次回复提炼） |
| 长期记忆 | 联系人/群独立记忆，自动压缩，UI 可查流水 |
| 看图 | glm-5.3-flash 原生视觉，可选专用视觉模型覆盖 |
| 联网搜索 | 两步法：启发式触发 → 智谱搜索 API（需搜索资源包）→ 结果注入回答 |
| 表情包 | 三库体系（人设专属/通用/QQ收藏），备注标签、缩略图、收藏同步、收藏库可开关 |
| 防滥用 | 总开关（默认开）：人设防篡改（注入话术免疫）+ 任务拦截（竞赛题/代写回绝）+ 身份锚定 |
| **主人任务沙箱** | 主人发「任务：…」→ 微型编码代理在沙箱执行（WRITE/RUN/READ 循环）→ 结果自动回传 |
| **私聊遥控** | 主人私聊：状态/用量/人设切换/群管理/功能开关/暂停恢复/日志/帮助 |
| **AI 生图** | 主人「画：描述」或自然说法（帮我画一张…）→ CogView-3-flash（免费档）生成并发图 |
| **夜间复盘** | 每日 03:30 自动统计+提炼风格观察+日报发主人私聊 |
| 用量统计 | GLM 官网风格：总量/30天/7天/当日 + 趋势曲线（时间范围切换）+ 按模型明细 |
| 桌面应用 | pywebview 窗口（ZCode 同款设计语言，日夜双主题自动跟随）+ 托盘 + 关闭三模式 + 开机自启 + UI 看门狗自愈 |
| 运行日志 | 独立页签实时汇聚 daemon/agent/启动任务三源日志 |

## 架构

```
QQ ←→ NapCat Shell(OneBot v11 WS :3001) ←→ qq_daemon.py（消息管道 :39763，零文件写入）
                                              ↕ HTTP 收件箱轮询
qq_bot_agent.py（自治大脑 :39764）
  模型链降级+思考模式 / 人设+防滥用 / 记忆 / 表情包 / 搜索 / 任务桥 / 遥控 / 生图 / 复盘
        ↕ spawn（沙箱）              ↕ HTTP（本机回环）
qq_task_worker.py（任务执行器）     qq_admin_ui.py（管理台 :39765）
                                       ↕ pywebview
qq_app.py（桌面窗口 + 托盘 + 看门狗）
```

- 数据目录：`~/.zcode-qq-bot/`（token/人设/风格/记忆/表情包/日志/用量/任务沙箱）
- 全部组件仅绑定 127.0.0.1；配置按 mtime 秒级热加载（管理台保存即生效）；daemon 零文件写入
- 源码在 `scripts/`，开发/调试在 ZCode 工作区进行（见 SKILL.md）

## 主人专属能力（ZCode 生态差异点）

设置页配置 `owner_qq` 后生效，普通群成员不可用：

1. **任务沙箱**：群里 @机器人 或私聊发「任务：…」（或整段任务型内容），转交沙箱执行器完成
   写代码/跑脚本/处理数据，产物落在 `task_workspace`（默认 `~/.zcode-qq-bot/tasks/`，
   可指向 ZCode 工作区子目录 → 产物直通 ZCode 工作台，随时在 ZCode 会话中接管续作）。
   限并发 1、每小时 6 次、单任务总预算 8 分钟、RUN 走程序白名单+参数列表。
2. **私聊遥控**：私聊发 `帮助` 查看全部指令。
3. **生图**：`画：描述` 或「帮我画一张…」等自然说法，CogView-3-flash 免费档，失败自动重试。

## 使用

双击桌面「ZCode QQ机器人」→ 状态页「启动机器人」（NapCat 登录阶段自动弹出 WebUI 扫码页，启动日志实时显示每一步）。首次使用：安装 QQ 与 NapCat Shell（详见 SKILL.md 运维手册）→ 设置页填机器人 QQ / 主人 QQ / 智谱 API Key。

## 安全与隐私

- 机器人会读取并处理所在群/好友消息；仅在自有账号、知情合规场景使用
- daemon/agent/UI 仅绑定 127.0.0.1（token 鉴权 daemon/agent；UI 无鉴权勿暴露）
- 风格模仿仅语言风格，不冒充身份；防滥用防护默认开启（防注入/防任务滥用/防设定泄露）
- 任务沙箱：入参路径强制校验、RUN 白名单、总预算限制；仅主人可触发
- 图片/外链下载仅允许公网 http/https 并拒绝环回/私有地址（防 SSRF）
- 消息流水日志在 `~/.zcode-qq-bot/logs/`（含聊天内容），自行妥善保管
